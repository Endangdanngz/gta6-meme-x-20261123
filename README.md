## About this entry

The entry is an X post: a GTA 6 meme made for make.fun's gta6-meme-x-01
bounty — the make.fun ghost, sunglasses on, leaning against a pink
convertible under a neon make.fun billboard in Vice City, posted publicly
with the bounty play code in its text:

https://x.com/ImanuelLung/status/2124759113695670623

`main.ts` (Node 22, standard library only) copies `POST.json` from the
repository root to the output directory, where the house reads the post's
address, fetches the post from X, and hands its picture and text to the
judge. Nothing else is judged.
